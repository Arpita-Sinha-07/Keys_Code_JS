# 🎯 About

**Keys Code JS** is an interactive frontend project built using **Vanilla JavaScript**, designed to visualize keyboard events in real time.

The application captures user key presses and dynamically displays:

* Key values
* Key codes
* Event information
* Keyboard interactions

This project demonstrates strong understanding of:

✅ DOM Manipulation
✅ Event Handling
✅ Dynamic UI Updates
✅ JavaScript Fundamentals
✅ Interactive Frontend Development

# ⚙️ How It Works

### Step 1

User presses a keyboard key.

↓

### Step 2

JavaScript listens for the keyboard event.

↓

### Step 3

Event data is captured:

* Key Name
* Key Code
* ASCII Information
* Event Metadata

↓

### Step 4

UI updates dynamically using DOM manipulation.

# 💡 JavaScript Concepts Used

## Event Listener

```javascript
window.addEventListener("keydown", (event) => {
  console.log(event.key);
});
```
